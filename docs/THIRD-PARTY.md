# 第三方素材与许可

模型、人物照片、立绘和音效沿用导入源码。公开源码不代表所有素材都有再分发许可，仓库未对整个游戏授予统一开源许可证。

Three.js 和加载器位于 `dist/vendor/`。MIT 许可完整保存在 [THREE-LICENSE.md](../dist/vendor/THREE-LICENSE.md)，仅变更扩展名，打包必须携带。

音频来源集中在 [SOURCES.md](../dist/assets/audio/SOURCES.md)。同目录 JSON 保留下载来源、文件名和摘要等机器可读信息，用于验证原始文件。来源记录不构成额外授权。

新增或替换素材应记录来源和授权范围，由维护者确认公开发布的适用范围。
