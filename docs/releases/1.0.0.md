# 合肥惊魂夜 1.0.0

新分发序列的首个正式版本。玩法基于原 v1.34.1，联机协议继续使用 36。

- 新增桌面登录器，自动检查更新，支持手动下载、取消和重启更新。
- 优先使用 GitHub Release，检查或下载失败时切换管理员配置的 HTTPS 备用源。
- Ed25519 签名清单及文件大小、SHA-256 校验；失败时保留当前版，离线可启动已有游戏。
- 登录器与游戏整体更新，已安装新版通过本机版本指针启动。
- 旧 TXT 重整为玩家指南、联机指南和素材说明，完整保留第三方许可。
- 增加分发 SOP、签名打包工具、发布草稿工作流和回归验证。
- 保留 Olo 的新模型、双道具栏、yzm 即时营救及踢猫/踢狗奖励，以及其他角色、地图、AI、技能道具、库奇、猫咪及现有 P2P 玩法，不引入账号系统或游戏中继。

运行配置由管理员独立交付，公开源码和 Release 不包含部署地址、SSH 信息及签名私钥。
