# 联机指南

分发版本 1.0.0，联机协议 36。请所有玩家使用同一正式版本。最多五名真人玩家，空位由 AI 补齐。

## 房间号联机

1. 房主在“多人联机”创建房间并分享六位房间号。
2. 其他玩家输入同一个号码加入，无需逐人生成邀请或回应。
3. 显示已直连后选择角色，客人点击“我已准备”，房主开始对局。

房间号需要管理员提供的运行配置，见 [SOP](../SOP.md#运行配置隔离)。仓库不包含实际服务地址。服务仅交换 WebRTC 连接信息；角色、准备、开始、移动、技能、位置和结算通过 P2P。服务断开不影响已连接对局，新玩家通过房间号加入需要服务可用。

## 手动直连

当房间号服务不可用、未配置或使用局域网时，打开“高级：手动直连”：

1. 房主创建手动房间，为每名玩家生成独立邀请。
2. 玩家导入邀请，将生成的回应发给房主。
3. 房主导入对应回应，直连成功后选人、准备并开始。

不依赖房间号服务。公共 STUN 仅帮助发现网络地址，不转发对局数据，也不能保证所有网络均能穿透。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 未配置房间号服务 | 获取管理员配置，或使用手动直连 |
| 房间不存在 | 核对号码，确认房主未退出或重建房间 |
| 满员 / 已开始 | 等待空位或房主返回选人 |
| 版本不同 | 所有人更新后重新创建房间 |
| 无法直连 | 双方退出 VPN / 加速器，尝试换房主或网络 |
| 加入停滞 | 点击“返回 / 取消”，检查网络后重试 |
| 移动延迟 | 检查网络与房主帧率，长时间断线后重连 |

对局采用房主权威判定、本地预测和位置插值，重复发送最近 600 毫秒未确认移动指令，用于缓解丢包，不能消除网络故障。

没有游戏中继或 TURN 兜底。登录器备用源只提供更新文件，不能替代 P2P 路径。无法直连时可先玩单人 AI。

排查时优先分享游戏提供的去敏连接诊断，不在公开 Issue 提交 IP、SDP、运行配置或原始服务器日志。
