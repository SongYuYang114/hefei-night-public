# 合肥惊魂夜 v1.34.1

正式开发仓库：https://github.com/galaxy-of-homos/hefei-night 。后续开发在此仓库进行。

当前联机协议为 36。七名求生者，包含 Olo；两名追杀者。对局数据走 P2P，六位房间号服务仅交换连接信息。

最新 Olo 使用卷发眼镜骨骼模型和新立绘，角色完全不透明。E、Q 各有一个道具位，使用 yzm 可以立即营救附近队友；不能普通营救或修机。基础移速 7.4 米/秒，免疫伤害与状态。踢库奇三次获得道具，不能获得不可思议的蛋或回血道具，踢猫力度随机。维修完成的电机显示人像投影。

## 从源码运行与构建

需要 Windows x64 与 Node.js 24：

```powershell
npm ci
npm start
npm run build
```

构建产物位于上一级 build-v1.34.1/。游戏逻辑和运行资源直接位于 dist/，原始模型在 resources/models/，导出、构建和验证脚本在 tools/。

不要提交 node_modules、EXE、构建产物、私钥和本机凭据。仓库里的 PEM 是公开证书。人物、照片、模型和音效包含用户提供或已有素材，本仓库未授予第三方素材的再分发许可，也未自动附加开源许可证。
